# OFFLINE

AI detective game inside an iPhone-inspired interface.

## Railway
Set:
- OPENROUTER_API_KEY = your OpenRouter key
- OPENROUTER_MODEL = optional; defaults to openrouter/free
- APP_URL = optional Railway public URL

Start command: npm start

The OpenRouter key stays server-side. The browser only sends the player's creative profile: alias, vibe, and fictional setting. It does not read contacts, files, precise location, private accounts, or browsing history.
